# KeepAlive

Sistem personal de evaluare biologică și prevenție.

**Plan V5** — focus pe scoruri validate din research publicat, aplicate pe markerii existenți (sânge + Oura + epigenetic).

## Stack

- Next.js 15 + TypeScript + Tailwind
- Supabase (client pregătit)
- Deploy: Vercel

## Prima versiune

- Evaluare pe domenii (cardiovascular, metabolic, inflamație, vârstă biologică)
- Cele 5 componente din plan
- Icon pentru home și web app pe iPhone
- Placeholder-uri pentru scorurile prioritare (PhenoAge, SCORE2, PREVENT)

## Rulare

```bash
npm install
npm run dev
```

**Nu este un dispozitiv medical.** Pentru uz personal și cercetare. Discută orice rezultat cu un medic.
